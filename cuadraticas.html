Las fórmulas que no puedes olvidar

Cuadrado de binomio

(a ± b)² = a² ± 2ab + b²
(a + b)(a − b) = a² − b²

Fórmula general

x = ( −b ± √(b² − 4ac) ) / 2a
Δ = b² − 4ac

Vértice de la parábola

h = −b / 2a   k = f(h)
f(x) = a(x − h)² + k

Suma y producto de raíces

x₁ + x₂ = −b/a
x₁ · x₂ = c/a

Los errores que más cuestan

(a + b)² = a² + b²→a² + 2ab + b²

El término del medio es el que casi siempre se olvida. Aparece en una de cada tres preguntas del eje 1.

h = b / 2a→h = −b / 2a

El signo menos. Si b es negativo, el vértice queda a la derecha del eje Y.

2x² + 10x − 12 = (x−1)(x+6)→2(x−1)(x+6)

Si a ≠ 1, saca primero el factor común. Las raíces no cambian, pero la función sí.

(x + 3) / 3 = x→no se simplifica

Solo se cancela lo que multiplica, nunca lo que suma. Factoriza antes de tachar.

Δ < 0 ⟹ no tiene solución→no tiene soluciones reales

La PAES pregunta por soluciones en ℝ. Δ < 0 significa que la parábola no toca el eje X.

a < 0 ⟹ el vértice es mínimo→es un máximo

Si abre hacia abajo, el vértice es el punto más alto. Clave en problemas de proyectiles y de área.

(x − 3)(x − 4) = 2 ⟹ x = 3 o x = 4→iguala a cero primero

La propiedad del factor cero solo sirve cuando el producto es 0. Si no, desarrolla y ordena.

Expresiones algebraicas

Todo se reduce a dos movimientos: desarrollar un producto o factorizar una suma. Si reconoces el patrón, el ejercicio dura veinte segundos.

Productos notables

  • (a + b)² = a² + 2ab + b²
  • (a − b)² = a² − 2ab + b²
  • (a + b)(a − b) = a² − b²Diferencia de cuadrados. La más frecuente.
  • (x + p)(x + q) = x² + (p + q)x + p·qEl puente entre factorizar y resolver ecuaciones.

Despejes que la PAES repite

  • a² + b² = (a + b)² − 2abTe dan la suma y el producto, y piden la suma de cuadrados.
  • (a − b)² = (a² + b²) − 2abEl ejercicio 43 de tu pizarra: 29 − 20 = 9.
  • (a + b)² − (a − b)² = 4ab
  • Si x₁ y x₂ son raíces: x² − (x₁+x₂)x + x₁·x₂ = 0

Fracciones algebraicas · el orden importa

  • 1 · Factoriza numerador y denominadorNunca simplifiques antes de factorizar.
  • 2 · Dividir es multiplicar por el recíproco de la segunda
  • 3 · Cancela solo factores completos
  • 4 · Anota la restricción: el denominador ≠ 0

Práctica · 11 preguntas

Ecuación cuadrática

ax² + bx + c = 0, con a ≠ 0. Antes de aplicar la fórmula, mira si b o c valen cero: te ahorras la mitad del trabajo.

Los cuatro caminos, de más rápido a más lento

  • b = 0 → x² = −c/a → x = ±√(−c/a)x² − 4 = 0 → x = ±2
  • c = 0 → x(ax + b) = 0x² + 3x = 0 → 0 y −3. Nunca dividas por x: pierdes la raíz 0.
  • Factorizar → busca p·q = c y p + q = bx² + 2x − 15 = (x+5)(x−3) → −5 y 3
  • Fórmula general → cuando nada calzax = (−b ± √(b²−4ac)) / 2a

Discriminante Δ = b² − 4ac

  • Δ > 0 → dos soluciones reales distintasLa parábola corta el eje X en dos puntos.
  • Δ = 0 → una solución real (doble)La parábola es tangente al eje X.
  • Δ < 0 → ninguna solución realLa parábola no toca el eje X.

Sin resolver la ecuación

  • x₁ + x₂ = −b/a
  • x₁ · x₂ = c/aSirve para preguntas con parámetros, sin calcular raíces.
  • Reconstruir: x² − (suma)·x + (producto) = 0

Práctica · 13 preguntas

Función cuadrática

La misma expresión, ahora dibujada. Mueve a, b y c y observa qué cambia: es la forma más rápida de fijar los conceptos.

Qué controla cada letra

  • a → concavidad y anchoa > 0 abre hacia arriba (mínimo); a < 0 hacia abajo (máximo). |a| grande = más angosta.
  • b → desplaza el vértice de ladoJunto con a define el eje de simetría x = −b/2a.
  • c → corte con el eje YSiempre en (0, c). Regalo de pregunta.

Las tres formas de escribirla

  • General: f(x) = ax² + bx + cLees c de inmediato.
  • Canónica: f(x) = a(x − h)² + kLees el vértice (h, k) de inmediato.
  • Factorizada: f(x) = a(x − x₁)(x − x₂)Lees las raíces de inmediato.

Traslaciones desde f(x) = x²

  • f(x − h) → h unidades a la derecha(x − 3)² se mueve a la derecha, aunque diga menos.
  • f(x + h) → h unidades a la izquierda
  • f(x) + k → k unidades hacia arriba
  • −f(x) → se refleja respecto al eje X
